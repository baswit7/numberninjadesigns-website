# Architecture

## Project Type

Web app.

## Recommended Shape

- Static HTML/CSS/JavaScript unless a framework is justified by product requirements.
- Mobile-first responsive layout.
- Local-first development path.
- Clear separation between UI, state, and data adapters.

## Boundaries

- No provider calls are included by this template.
- No deployment automation is included by this template.
- No credential storage is included by this template.
- No background services are included by this template.

## Performance Defaults

- Keep the first load small.
- Defer non-critical assets.
- Avoid unnecessary dependencies.
- Measure layout stability before adding animation.
