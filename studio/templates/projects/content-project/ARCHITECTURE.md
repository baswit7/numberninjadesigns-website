# Architecture

## Project Type

Content project.

## Recommended Shape

- Keep planning, drafts, assets, and publishing notes separated.
- Use simple status fields before adding process tooling.
- Track source, channel, and owner for each asset.
- Keep platform-specific details documented without invoking platforms.

## Boundaries

- This template does not publish content.
- This template does not call social or marketplace providers.
- This template does not store credentials.
- This template does not add schedulers, workers, queues, or deployment automation.

## Performance Defaults

- Batch similar content tasks.
- Keep reusable channel notes close to the campaign.
- Avoid duplicating canonical product or brand data.
