# Codex Working Rules

## Scope

Build only the content project described in `PROJECT_MASTER.md`.

## Delivery Rules

- Keep audience, offer, channel, and status visible.
- Reuse brand and product source material instead of duplicating truth.
- Keep platform credentials and publishing actions outside this template.
- Do not add governance, approval, provider invocation, deployment automation, workers, queues, schedulers, or agent orchestration.

## Validation

- Verify the first content batch has owner, channel, and status.
- Verify no credentials are committed.
- Record meaningful changes in `CHANGELOG.md`.
