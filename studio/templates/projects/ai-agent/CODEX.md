# Codex Working Rules

## Scope

Build only the AI agent project described in `PROJECT_MASTER.md`.

## Delivery Rules

- Keep the agent job narrow.
- Add examples before implementation.
- Keep provider values out of the repository.
- Do not add governance, approval, provider invocation, deployment automation, workers, queues, schedulers, or agent orchestration.

## Validation

- Verify task examples cover expected and failure cases.
- Verify no credentials are committed.
- Record meaningful changes in `CHANGELOG.md`.
