# Etsy Listing Workflow - NumberNinjaDesigns

## Purpose

This workflow turns one product idea into a review-ready Etsy listing without automation, provider calls, credential handling or publishing actions.

It is built for the NumberNinjaDesigns brand:

- dark tactical premium
- data, Excel and programming audience
- witty, direct and conversion-focused
- no corporate tone

## Workflow States

| State | Owner | Output | Exit Criteria |
| --- | --- | --- | --- |
| Idea intake | Bas | Product idea card | Audience, joke angle and product type are clear |
| Keyword pass | Bas or Codex | Keyword set | Primary keyword, long-tail keywords and tag candidates exist |
| Listing draft | Codex | Title, description, tags, image plan | Copy follows brand tone and Etsy constraints |
| Asset pass | Bas | Mockup/content checklist | Required mockups and content assets are identified |
| Price pass | Bas | Price note | Price, margin assumption and discount stance are explicit |
| Review | Bas | Review checklist | SEO, copy, assets, compliance and brand fit are checked |
| Release ready | Bas | Publishing checklist | Listing can be manually entered into Etsy |

## Product Idea Intake

Use this structure for every product idea.

| Field | Required Input |
| --- | --- |
| Product idea | Short concept name |
| Audience | Data analyst, Excel user, programmer, accountant, operator or niche persona |
| Joke angle | The exact witty/direct idea |
| Product format | Shirt, hoodie, mug, sticker or digital mockup target |
| Buyer intent | Gift, self-expression, work humor, niche pride or team identity |
| Visual direction | Typography-only, code-style, spreadsheet-style, chart-style or tactical badge |
| Risk notes | Trademark, profanity, ambiguity, weak joke or crowded keyword |
| Confidence | 1-10 |

## Keyword Research Checklist

No API calls are required. Use manual Etsy search, Etsy autocomplete, marketplace observation or prior project notes.

Required:

- [ ] Primary keyword selected.
- [ ] Three to five long-tail keyword candidates selected.
- [ ] Thirteen Etsy tag candidates drafted.
- [ ] Audience terms included.
- [ ] Product-format terms included.
- [ ] Gift/search intent terms included where relevant.
- [ ] Trademark-sensitive terms excluded.
- [ ] Overly broad terms reduced or paired with niche modifiers.

Keyword pattern:

```text
[audience] + [joke/theme] + [product format]
```

Examples:

- `data analyst shirt`
- `excel humor t shirt`
- `sql developer gift`
- `spreadsheet joke hoodie`
- `programmer coffee mug`

## Listing Title Formula

Use a readable title. Do not keyword-stuff beyond the point where a human buyer would distrust it.

Formula:

```text
[Core phrase], [Audience phrase], [Product format], [Gift/use phrase], [Brand tone phrase]
```

Example:

```text
Data Analyst Shirt, Excel Humor Tee, Spreadsheet Gift, Tactical Tech Office Shirt
```

Title rules:

- Lead with the strongest buyer/search phrase.
- Keep the first 45 characters understandable.
- Include the audience before generic product language where possible.
- Use separators sparingly.
- Avoid claims that require proof.
- Avoid trademarked product names unless usage is clearly allowed.

## Description Structure

Use this structure for every listing.

### Opening Hook

One or two direct lines that signal the joke and audience.

Pattern:

```text
Built for [audience] who [pain/joke/identity]. Clean enough for work, sharp enough for the spreadsheet war room.
```

### Product Fit

Explain who it is for and when it works.

Include:

- audience
- gift use case
- work or hobby context
- product format

### Design Notes

Describe the design without overpromising.

Include:

- typography or visual style
- color/mood
- tactical tech feel
- readability

### Ordering Notes

Keep this neutral and operational.

Include:

- check size/color options in Etsy
- verify shipping estimate in Etsy
- review mockup images before purchase

### Closing Line

Short brand-consistent close.

Examples:

- `For people who debug spreadsheets before breakfast.`
- `Tactical gear for spreadsheet operators.`
- `Built for the ones who know the formula is the battlefield.`

## Etsy Tags Structure

Draft thirteen tags before publishing.

Tag mix:

| Tag Type | Count | Example |
| --- | ---: | --- |
| Audience | 3 | `data analyst`, `excel user`, `programmer gift` |
| Product | 2 | `office shirt`, `tech hoodie` |
| Joke/theme | 3 | `spreadsheet humor`, `sql joke`, `debug mode` |
| Gift intent | 2 | `coworker gift`, `nerd gift` |
| Brand style | 2 | `tactical tech`, `data nerd` |
| Variant/niche | 1 | `accounting humor` |

Rules:

- Do not repeat the exact same phrase in every tag.
- Prefer specific buyer language over vague style words.
- Exclude protected brands, software marks and celebrity names unless legally cleared.
- Avoid irrelevant trend tags.

## Image And Mockup Checklist

Every listing needs a clear asset plan before manual Etsy entry.

Required image set:

- [ ] Primary product mockup with readable design.
- [ ] Close-up crop showing text/detail.
- [ ] Lifestyle or desk-context mockup.
- [ ] Size or fit guidance image if apparel.
- [ ] Color option image if variants exist.
- [ ] Brand-consistent dark tactical premium visual where appropriate.
- [ ] Plain high-contrast image for mobile scanning.

Asset quality rules:

- Text must be readable on mobile.
- Mockups must not hide the actual design.
- Do not use misleading product context.
- Keep colors close to actual product options.
- Avoid over-darkening product detail.

## Price Notes

Before publishing, write a short price note.

Required:

- [ ] Base cost known or estimated.
- [ ] Etsy fees considered.
- [ ] Shipping impact considered.
- [ ] Target margin noted.
- [ ] Discount stance noted.
- [ ] Price does not rely on an unverified claim.

Simple note format:

```text
Target price:
Cost assumption:
Margin assumption:
Discount rule:
Reason:
```

## Listing Creation Checklist

Use this before manual Etsy entry.

- [ ] Product idea intake is complete.
- [ ] Primary keyword selected.
- [ ] Long-tail keyword list selected.
- [ ] Title follows the title formula.
- [ ] Description follows the required structure.
- [ ] Thirteen tags drafted.
- [ ] Mockup checklist complete.
- [ ] Price note complete.
- [ ] Trademark/protected-term check complete.
- [ ] Brand tone check complete.
- [ ] Mobile readability check complete.
- [ ] Manual publish owner confirmed.

## Review Checklist

Before a listing becomes release-ready:

- [ ] The first title phrase matches likely buyer search intent.
- [ ] Copy is witty/direct, not corporate.
- [ ] The design/audience match is obvious within five seconds.
- [ ] The description does not claim features, quality or guarantees not shown in the listing.
- [ ] All tags are relevant to the product.
- [ ] Mockups show the actual design clearly.
- [ ] Price note is complete.
- [ ] No credentials, API data or automated publish step is involved.
- [ ] Final manual Etsy entry is still human-controlled.

## Publishing Checklist

This checklist prepares manual publishing only.

- [ ] Etsy listing fields are ready to copy manually.
- [ ] Title is final.
- [ ] Description is final.
- [ ] Tags are final.
- [ ] Images/mockups are final.
- [ ] Price is final.
- [ ] Product variants are known.
- [ ] Shipping/profile assumptions are known.
- [ ] Manual reviewer approved release readiness.
- [ ] No automation or provider execution is used.
