# Design Brief - Pivot Table Operator

## Product

`Pivot Table Operator`

## Creative Goal

Create a premium tactical-tech shirt design for spreadsheet-heavy professionals who use pivot tables as their office command tool.

The design must feel:

- sharp
- technical
- dark
- premium
- analyst-specific
- readable on a shirt and Etsy mobile mockup

It must not feel:

- corporate
- childish
- generic novelty shirt
- cluttered
- like a spreadsheet tutorial

## Shirt Front Concept

Primary front text:

```text
PIVOT TABLE
OPERATOR
```

Secondary microcopy options:

```text
SPREADSHEET RECON UNIT
ROWS COLUMNS VALUES FILTERS
DATA SUMMARY DIVISION
```

Recommended composition:

- centered tactical badge or stacked operator label
- `PIVOT TABLE` as the upper line
- `OPERATOR` as the dominant lower line
- small spreadsheet-grid detail behind or below the wordmark
- subtle labels for pivot-table fields around the design
- optional small coordinate-style marks in the corners

## Typography Guidance

Primary typography:

- condensed uppercase sans-serif
- strong vertical presence
- high legibility at thumbnail size
- inspired by Bebas Neue or Orbitron-style geometry

Secondary typography:

- monospaced technical microcopy
- inspired by JetBrains Mono
- use sparingly for labels and small operator details

Hierarchy:

1. `OPERATOR`
2. `PIVOT TABLE`
3. `SPREADSHEET RECON UNIT`
4. tiny field labels

Avoid:

- script fonts
- distressed grunge fonts
- playful rounded lettering
- tiny spreadsheet cells that become unreadable

## Icon Concepts

Use one or two icon ideas only. Do not overload the shirt.

Recommended icons:

- minimal spreadsheet grid
- four-field pivot layout: rows, columns, values, filters
- small crosshair alignment marks
- operator badge outline
- tiny stacked data blocks
- summary table icon

Optional detail:

```text
ROWS | COLUMNS | VALUES | FILTERS
```

Avoid:

- official Excel logos
- official Microsoft branding
- generic laptop icons
- cartoon office characters
- complex charts that compete with the main phrase

## Layout Options

### Option A - Tactical Badge

- shield or rectangular patch outline
- `PIVOT TABLE` top
- `OPERATOR` center, largest
- grid fragment below
- microcopy: `SPREADSHEET RECON UNIT`

Best for:

- premium shirt mockups
- brand consistency
- strong thumbnail recognition

### Option B - Spreadsheet Command Label

- design resembles a technical equipment label
- stacked all-caps text
- small field labels aligned like a compact table
- no badge outline, more minimal

Best for:

- clean black shirts
- understated office wear
- high readability

### Option C - Pivot Field Interface

- abstract pivot-table field panel
- `ROWS`, `COLUMNS`, `VALUES`, `FILTERS` as small tactical labels
- `PIVOT TABLE OPERATOR` overlaid as command text

Best for:

- audience specificity
- visual link to spreadsheet culture
- later mockup variants

## Color Recommendations

Primary shirt colors:

- black
- charcoal
- dark navy
- deep forest

Core design palette:

- text: `#EDEBE3`
- accent: `#00FF94`
- muted detail: `#777777`
- dark support: `#0F0F0F`

Recommended print balance:

- 80 percent light text
- 15 percent muted technical detail
- 5 percent green accent

Use green accent only for:

- small field labels
- grid highlight
- operator mark
- one thin line or dot system

Avoid:

- large green filled blocks
- neon overload
- low-contrast gray text
- more than three visible colors

## Premium Tactical NumberNinjaDesigns Style

Style rules:

- dark tactical premium, not gamer neon
- exact and disciplined, not chaotic
- data-literate, not generic tech
- office-ready, not childish
- witty through the phrase, not through clipart

Visual references to imply:

- field operator patch
- technical dashboard label
- spreadsheet control panel
- analyst command station
