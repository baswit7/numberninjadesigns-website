Official Brand: NumberNinjaDesigns

API access is requested only for authorized NumberNinjaDesigns brand accounts and only through official platform APIs, approved permissions and OAuth flows where required.

Etsy Open API v3

Use case: Read the owner's shop and listing metadata, create or update draft listings, and synchronize approved NumberNinjaDesigns product metadata. Users: The NumberNinjaDesigns shop owner only. Scopes: listings_r, listings_w and shops_r; no buyer, address, payment, favorites, profile or transaction scopes are requested. Authorization: OAuth 2.0 Authorization Code with PKCE, single-use state and an exact HTTPS redirect URI. Human approval: Public listing activation and shop-sensitive changes remain manual. Data: Only shop and listing metadata required for this internal workflow. Restrictions: No scraping, resale, advertising profiles, buyer surveillance, password collection or access by unrelated accounts.

Security Principles

  • Least Privilege
  • OAuth 2.0 with PKCE and single-use state
  • Server-side encrypted token storage; API secrets and tokens never enter browser code or localStorage
  • Refresh-token rotation, explicit reconnect handling and exact HTTPS redirect matching
  • Rate-limit handling, bounded retry for read requests and idempotent write synchronization
  • Audit events exclude tokens, credentials and personal data
  • No Credential Collection
  • No Password Storage
  • No Login Automation
  • No Scraping
  • No Reverse Engineering
  • Human Approval
  • Respect Platform Policies

Data Handling

Etsy data is used only for authorized NumberNinjaDesigns listing preparation and shop operations. API credentials and OAuth tokens remain on the private server; operational logs contain status and technical error codes, not listing content, buyer data or tokens.

Data Retention

OAuth tokens are deleted when the Etsy connection is disconnected or no longer required. Cached shop or listing metadata is minimized, refreshed when needed and deleted following a verified deletion request unless retention is legally required.

Incident Reporting

Suspected platform, privacy or security incidents can be reported through the official contact address and will be reviewed with priority.
