### Changed

- The active Product Factory architecture moved from the preserved four-sheet baseline description to a contract-driven fourteen-definition catalog.
- Active products now receive safe sample data, populated lookup content, customer instructions, and selected product-specific analysis/lookup sheets.
- Workbook formulas are generated through a 29-operation allowlisted registry and recalculated by the target spreadsheet application.
- Browser generation and packaging use local vendor assets. The local server can persist verified XLSX/ZIP/PNG output directly under `output/generated-products`, with browser-download fallback; no CDN or remote backend is required.
- The release-certified compatibility target is now limited to Excel Desktop 2019+; Excel Web, LibreOffice, and Google Sheets are explicitly non-certified.
- Browser and production-matrix packages remain `DRAFT`; only successful native exact-byte evidence can produce `READY_FOR_REVIEW`.
- `npm test` now discovers the complete Node test corpus; focused production validation remains available through `npm run test:production`.

### Security

- Added formula-prefix neutralization, safe JSON structure limits, prototype-key rejection, safe filenames, path-safe ZIP assembly, payload hashes, and fail-closed formula operation resolution.
- Added deterministic package validation for fixed inputs and explicit separation between structural, quality, compatibility, local decision state, and external review boundaries.
- Added verification that the exact workbook bytes tested by the compatibility probe are the bytes included in the commercial package.
- Added final-ZIP reopening and rejection of missing, malformed, duplicate, reordered, or checksum-mismatched listing images.

### Evidence boundary

- Structural production-matrix evidence intentionally remains compatibility `PARTIAL` and release `DRAFT`.
- Stored performance and native evidence created under the earlier five-product policy is historical and environment-specific; it does not certify the current catalog or physical-image gate.
- No automated status constitutes marketplace publication. Physical Photoshop and ElevenLabs production requires the locally licensed/configured providers and remains covered by fail-closed evidence gates.
