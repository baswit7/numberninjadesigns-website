# Generated output storage

The local generator stores workbook, Etsy-image and commercial-package exports inside the
repository instead of relying on the browser's global Downloads directory.

## Product output

The deterministic destination is:

```text
output/generated-products/<product-id>/<locale>/<currency>/<palette>/<appearance>/v<version>/<filename>
```

Example:

```text
output/generated-products/budget-planner-professional/de-DE/EUR/executive-navy/dark/v1.0.0/budget-planner-professional_de-DE_EUR_executive-navy_dark_1.0.0.zip
```

Individual Etsy PNG files are written below the same variant:

```text
output/generated-products/<product-id>/<locale>/<currency>/<palette>/<appearance>/v<version>/listing/images/<filename>
```

The optional Etsy-image ZIP is stored beside the workbook and sales package.

Batch archives use a separate run directory:

```text
output/generated-products/batches/<run-id>/finance-product-factory-batch.zip
```

`output/` remains ignored by Git. Generated customer files therefore stay
local and cannot be committed accidentally.

## Runtime contract

The browser sends generated bytes to the same-origin `POST /api/output`
endpoint. The local server derives the destination from validated product
metadata and returns the exact relative path, byte count and SHA-256 digest.
The generator displays this path after a successful save.

The storage boundary rejects:

- absolute paths and path traversal;
- unknown product, locale, currency, palette, appearance or version formats;
- mismatched file extensions;
- payloads larger than 75 MB;
- ZIP/XLSX data without a ZIP signature and image data without a PNG/IHDR signature;
- a request media type that does not match workbook, package, image archive or PNG output;
- cross-origin, unknown-host and non-local browser requests;
- existing symlink or non-file destinations;
- any resolved destination outside the repository output root.

If the local storage endpoint is genuinely unavailable, the generator may
offer an explicit browser-download fallback and warns that the browser's
Downloads directory is being used. Validation or security failures never
fall back silently.
