# Legacy retirement plan

## Current state

Legacy repositories and folders remain untouched as rollback evidence. They are not canonical and must receive no new product, content, API or Studio OS work.

## Retirement sequence

1. Validate the unified repository locally.
2. Review the local `.env` variable coverage without exposing values.
3. Reconnect read-only Meta, Etsy, Pinterest, TikTok and Printify checks from the unified Studio layer.
4. Confirm the NumberNinjaDesigns website, Etsy shop and social account identifiers.
5. Change the existing social account display names, usernames, bios and visuals.
6. Keep old domains as permanent redirects to `https://www.numberninjadesigns.com`.
7. Freeze old repositories and mark them archived.
8. Delete local legacy folders only after an explicit deletion approval and a verified backup.

## Never delete during consolidation

- source Git history;
- human-approved product assets;
- licensing evidence;
- order/customer evidence required by law or platform policy;
- API review and OAuth compatibility records still used by a provider;
- release evidence for products that remain for sale.
