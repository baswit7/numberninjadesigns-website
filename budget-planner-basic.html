01

What the approved package contains

The approved launch package contains an XLSX workbook and a PDF guide inside a ZIP archive. No customer file is exposed from this preview.

  • Income and expense transaction tracking
  • Plan-versus-actual monthly budget
  • Savings-goal progress
  • 12-month cash-flow dashboard
  • Built-in model checks

02

A deliberate four-step flow

  1. Configure

    Set the workbook basics and review the Start instructions.

  2. Record

    Add personal income and expense transactions in the marked input cells.

  3. Review

    Compare monthly plan versus actual and inspect savings progress.

  4. Verify

    Use the Checks tab before acting on dashboard totals.

03

Compatibility

  • Microsoft Excel 2021 or later on Windows is the current verified baseline.
  • Google Sheets and other spreadsheet apps are not certified.
  • The interface shown here is a code-native structural preview.

Privacy & offline use

  • This page does not collect or transmit financial entries.
  • The workbook workflow keeps personal entries in the local file.
  • Checkout and digital delivery are handled by Etsy through the linked listing.

Important limits

  • Dashboard output depends on accurate user entries.
  • Use the workbook as an organizational aid and review totals before acting on them.
  • This is not financial, tax, legal or investment advice.
